This page documents the configuration options specific to `createFetchClient`. These options define the base behavior for all requests made with the created client instance.

Most options can also be set per request, where they override the base value. See [Extra Options](/docs/api-reference/extra-options) for those, and [Hooks](/docs/hooks), [Plugins](/docs/plugins) and [Validation](/docs/validation) for guides on the larger options.
