---
title: Extra Options
description: Options that can be passed to a CallApi instance
---

This page documents the CallApi-specific options you can pass to an individual request. Most of them can also be set in `createFetchClient`, where they apply to every request (see [Base Extra Options](/docs/api-reference/base-extra-options)).

For fetch options such as `headers`, `body` and `method`, see [Request Options](/docs/api-reference/request-options).
